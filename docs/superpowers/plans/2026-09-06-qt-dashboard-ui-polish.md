# Qt 监控面板界面收尾计划

## 目标

在现有 `MonitoringDashboard` 功能不变的前提下，移除顶部多余品牌文字，压缩导航栏高度，减少重复状态日志对左侧面板的占用，并统一预览区、设备区和云台区的视觉层级。

## 实施步骤

1. 为 `MonitoringDashboardTest` 增加顶部品牌控件不存在的回归断言。
2. 调整 `MonitoringDashboard::buildUi()` 的布局边距、控件尺寸、颜色和分栏比例，保留现有信号槽与业务入口。
3. 将状态日志规范化、连续重复消息合并并限制可见条数，避免 RTSP 重连错误刷屏。
4. 使用 Qt 5.14.2 MinGW 32-bit 重新构建并运行现有 Qt 测试集，检查差异只涉及客户端 UI。

## 验收标准

- 顶部不再显示 `SM`、`SMART HOME`、`MONITORING SYSTEM`。
- 实时预览、录像查询、设备数据按钮仍可点击并触发现有信号。
- 左侧状态列表最多保留 24 条，连续相同消息不重复添加。
- Qt 配置、构建和现有测试全部通过；不启动服务端、不进行真实 TCP 或摄像头联调。
