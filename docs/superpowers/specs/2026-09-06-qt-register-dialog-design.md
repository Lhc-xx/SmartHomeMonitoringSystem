# Qt 独立注册对话框设计

## 目标

将登录和注册从同一张表单中分离：登录页只负责登录，点击注册按钮后打开独立的模态注册对话框，注册成功后返回登录页。

## 范围与约束

- 只修改 `client/qt/SmartHomeClient` 的 Qt 客户端界面及对应测试。
- 复用现有 `UserService::registerUser()` 和注册信号，不修改 TLV、TcpClient、服务端或公共协议。
- 注册对话框使用 Qt Designer `.ui` 文件，遵循 Qt 5.14.2、C++11 写法。

## 交互设计

登录页保留用户名、密码和登录按钮；注册按钮文案改为“注册新账号”。点击后弹出标题为“注册新账号”的模态对话框，包含用户名、密码、确认密码、提交注册和取消按钮。提交前在界面层检查空值及两次密码一致性，网络注册结果只在对话框内显示。注册成功后对话框关闭，登录页自动填入注册用户名并提示“注册成功，请登录”。

## 组件边界

- `RegisterDialog`：管理注册表单、输入校验、注册结果展示和关闭行为；不直接构造协议或操作 socket。
- `LoginWidget`：管理登录表单，并负责打开注册对话框；注册信号连接从登录页移到注册对话框，避免两个窗口同时响应同一结果。
- `UserService`：保持现有注册接口和信号不变。

## 验收

1. 点击注册按钮能够打开独立对话框，登录页不会立即发起注册请求。
2. 空用户名、空密码、密码不一致时不会调用服务层，并显示明确提示。
3. 点击取消可以关闭对话框；注册成功或失败提示显示在对话框内。
4. 注册成功后回到登录页，用户名被保留，密码不被自动填充。
5. Qt 5.14.2 MinGW32 构建和现有测试全部通过。
